# Rivet Files

Rivet Files is the file manager of the Rivet desktop.

Its source, issues and releases live in the Rivet apps repository:
**https://github.com/rivetsoft/apps** (`apps/rivet-files`).

- Download: https://github.com/rivetsoft/apps/releases/latest
- Website: https://rivetsoft.github.io/files/

This repository exists so that the Flatpak app id `io.github.rivetsoft.rivet-files` resolves to a real page.
